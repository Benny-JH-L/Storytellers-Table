
### Keybinds ###

## Camera ##
WASD/Arrow keys:			move horizontally
Q/E:						to move the camera down/up (vertical movement)
Scroll wheel up/down:		zoom in/out

# Mouse Dragging #
middle mouse + shift key:									horizontal movment
middle mouse + ctrl/command key:							vertical movement
Middle mouse without shift, or ctr/command keys pressed:	camera rotation


## Campaign Modes ##
c: cycle between modes

# Map Edit #
left mouse click: select tile
1:  toggle single select
2:  toggle radial select
3:  toggle area select
4:  toggle draw select
`:  clear selected tiles/labels

\:  toggle tile/label mode
=:  toggle's tile/label placement (if off, tile edit is enabled)
-:  toggle's tile/label removal (if off, tile edit is enabled)
0:  toggle's tile/label edit
